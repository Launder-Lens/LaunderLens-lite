# Models

This folder contains the machine learning models used for the Anti-Money Laundering (AML) detection system.

## Models

The project includes the following models:

- Decision Tree
- Random Forest
- XGBoost
- Support Vector Machine (SVM)
- Graph Neural Network (GNN)

## Purpose

The classical machine learning models are used as baseline models for transaction-level AML detection.

The GNN is used to analyze relationships between accounts and transactions by representing the AML data as a graph.

Isolation Forest is used as an additional anomaly detection approach.
